# AirBox · 局域网快传

> 手机和电脑在同一个 Wi-Fi 下互传文件，不用装 App、不用数据线、不上传任何服务器。

手机扫桌面端显示的二维码 → 浏览器打开 → 传文件，就这么简单。

## 特性

- 📱 **手机免安装**：扫码即连，手机浏览器直接上传 / 下载
- 🔄 **双向互传**：手机→电脑（网页上传），电脑→手机（网页下载）
- 🔒 **随机令牌保护**：每次启动生成新链接，只有扫码者能访问；局域网其他人猜不到
- 🛡️ **文件名防穿越**：拒绝路径分隔符 / 控制字符，杜绝目录逃逸
- 📂 **收件目录可自定义**：默认 `~/Downloads/AirBox`，可随时切换
- 💾 **大文件无压力**：流式写盘，无大小限制，多文件带进度条
- ⚡ **本地直连**：局域网 P2P，文件不经过任何第三方服务器

## 使用

1. 打开 AirBox（桌面端）
2. 手机连**同一个 Wi-Fi**，用相机 / 浏览器扫桌面端二维码
3. 手机上选文件 → 传到电脑；或在网页上点文件下载到手机
4. 收到文件自动存到收件目录（默认 `~/Downloads/AirBox`）

## 开发

```bash
npm install
npm run tauri dev        # 开发模式（热更新）

npm run build            # 前端构建 + 类型检查
cd src-tauri && cargo test   # 后端接口测试
npm run tauri build      # 打包 .app / .msi
```

### 环境变量（测试 / 高级用法）

| 变量 | 说明 |
|------|------|
| `AIRBOX_PORT` | 固定服务端口（默认随机） |
| `AIRBOX_TOKEN` | 固定访问令牌（默认随机 8 位） |
| `AIRBOX_DIR` | 收件目录（默认 `~/Downloads/AirBox`） |

## 架构

```
桌面端（Tauri 2 + Vue 3 + axum）
├─ Rust HTTP 服务：0.0.0.0:随机端口
│   └─ /t/<token>/          手机网页（内嵌静态页）
│      ├─ api/files         文件列表
│      ├─ api/upload        上传（multipart 流式）
│      └─ api/files/:name   下载 / 删除
├─ LAN IP 检测（192.168.x.x，排除 VPN/虚拟网卡）
└─ 桌面 UI：二维码 + 复制链接 + 收件目录 + 文件列表
```

## 隐私

- 文件只在**本机局域网**内传输，绝不经过第三方服务器
- 服务随 AirBox 关闭而停止，链接令牌每次启动随机更换
- 详细设计见 `docs/superpowers/specs/2026-08-26-airbox-design.md`
